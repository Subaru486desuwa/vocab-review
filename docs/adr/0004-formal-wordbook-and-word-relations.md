# 正式考研词表取自开源词典，词对关系由词典与规则生成

2026-10-29 项目负责人决定：演示词库即将学完，改用正式词表作为词库，以便做词对的成对记忆，并完善“诊断 + 建议”。首个正式词表为考研。

- 词表与词义：取 ECDICT（MIT 许可）中带 `ky` 标签的词条；音标、中文释义、英文释义来自 ECDICT。中文释义按词性行拆成词义（vt./vi. 合并为 v.，WordNet 语料中未标注过的次要词性视为冷僻用法跳过），sense_key 为词性代码，同一原始数据重建时保持不变。已在演示词库中的词条沿用原有词义与题目，不覆盖已有作答。
- 例句：Tatoeba 中英句对（CC BY 2.0 FR），只取含目标词原形、长度适中的句子，按词性标注（NLTK 感知机）对应到词义；来源列记录句子编号。没有例句的词义不出语境题。
- 题目：三类题型由规则生成。辨义题干扰项优先取该词形近词的释义，其次同词性随机；排除近义词与释义有重叠的选项。拼写题题干与其他词相同时不出题。
- 词对关系：新增 `word_relations` 表与内容包 `relations.csv`，类型为近义（WordNet 同义词集）、派生（WordNet 派生指针）、形近（拼写编辑距离，排除词形变化、词尾与否定前缀变化）。关系是内容，按词条而不是词义连接。
- 使用方式：练习反馈展示该词的词对；诊断页对当前弱项列出词对及其当前证据，并可发起“成对练习”（复用 sense_ids 定向练习，ADR 0003）。词对只决定展示与用户主动发起的练习，不改变默认组卷、复习规则与学习状态。

来源标注为“ECDICT 考研标签”等真实来源，题目与词义拆分是规则生成，未经人工或 AI 逐条复核；词对不称为“易混词”认定。实验四检索评价仍以 v2 语料为准，诊断语义阈值不变。

被放弃的方案：

- 商业词汇书（红宝书等）：版权不允许入库，词条顺序与释义也无法公开复现。
- 用编码器相似度生成近义关系：阈值未经标注评价，且会把“错题语义组”（ADR 0002，模型参考）与内容关系混在一起。
- 词对关系按词义连接：WordNet 与 ECDICT 的义项无法可靠对应到拆分后的词义。

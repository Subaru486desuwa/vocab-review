# 学习诊断复用实验三、四的制品，只作参考展示

2026-10-26 项目负责人决定新增学习诊断页，用常用的 ML、DL 算法分析用户作答。首版边界原定“个人日志驱动的模型排序留待跨域验证后接入”，但本系统没有真实用户，演示与模拟账户的作答由规则或随机数生成，既无法做跨域验证，也不适合训练新模型（会学到模拟器自身的规则）。

因此诊断页不训练新模型：遗忘风险直接用实验三随机森林按 recall_features_v1 预测每个 词义 × 题型 的 expected_recall，再用 KMeans 对特征与预测值分组；错题语义用实验四 MiniLM 编码“词条: 英文释义”，做层次聚类并计算误选项的相似度。两者都标注为参考、未在本系统用户上验证；语义阈值固定为演示词库两两相似度的第 99 百分位，未经标注评价。模型结果只出现在诊断页与 `inference_events`（source_type=user_history），不改变组卷顺序、复习规则、学习状态和统计；模型不可用时规则统计照常。

被放弃的方案：在 Duolingo 英语记录上训练 GRU 知识追踪（DKT）。需要新的实验、评价与报告章节，挤占汇报前的彩排与缓冲时间；有真实用户数据后再评估。

# 规则证据驱动定向练习，模型仍只作参考

2026-10-27 项目负责人按架构调研的推荐方向（候选 01 + 02 最小切片）决定补齐“诊断 → 练习”的决策闭环，并参照 Duolingo 的半衰期回归（HLR）给出记忆强度。这部分修订 ADR 0002 中“诊断不改变组卷”的约定，范围如下：

- 新增当前证据 evidence_v1：按 词义 × 题型 从作答事实计算当前弱项、记忆衰减、已改善与记忆强度。记忆强度沿用 HLR 的形式 p = 2^(−Δ/h)、h = 2^(θ·x)，但 θ 为手工设定的固定值，不在本系统或 Duolingo 数据上训练；它是可复现的规则，只用于排序与解释，不是掌握度。
- 选题决策 selection_v1 使用这些证据：默认组卷的到期、错题与巩固项按记忆强度从低到高排列（原为同级随机）；新增用户主动发起的弱项专练（focus=weak）与按词义定向练习（sense_ids）。每题的选题理由写入练习目标快照。
- 复习安排升级为 review_rules_v2：未到复习时间的提前练习答对不再推进间隔。旧作答仍按其记录的 v1 重放。

保持不变：实验三随机森林、KMeans 与实验四编码器的输出仍只在诊断页作参考（ADR 0002），不进入组卷、复习安排与学习状态；模型不可用时决策闭环照常。

被放弃的方案：用实验三模型的 expected_recall 直接排序复习。该模型在 >30 天间隔子群差于均值基线，且未在本系统用户上验证。按本系统作答拟合 HLR 系数同样被放弃：现有作答来自演示与规则模拟，拟合会学到模拟器自身的规则。

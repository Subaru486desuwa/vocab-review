# 实施顺序与验收

当前完成项为架构、基础 Web 入口、Docker 中的 MySQL 与 0001 建表迁移、账户与会话（T02、T03 的登录部分）。学习业务与模型场景均待实现和执行；仅对实际运行项保存证据。

## 分阶段完成门槛

| 阶段 | 内容 | 完成门槛 |
| --- | --- | --- |
| S0 | 环境、依赖、MySQL 与配置 | 解释器和依赖锁可重建；数据库连接另行验证 |
| S1 / E1 | 工厂、路由、模板、静态图片 | 实际访问 /lab/hello；保存环境、启动日志与带地址栏截图 |
| S2 / E2 | MySQL、账户、导入、练习和复习 | 学习闭环、跨用户隔离、幂等与回滚通过 |
| S3 / E3 | ML 数据处理、训练、评价和实验页 | 离线/接口一致、真实基线和指标、MySQL 留证 |
| S4 / E4 | DL 模型、语料、索引和检索 | 本地前向、版本匹配、独立标注与 TF-IDF 对照 |
| S5 | 统一交接 | 干净环境启动、SQL 导出、实验报告与演示 |

## 功能验收 T01—T14

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| T01 | 基础路由与静态图片 | HTTP 成功，文字图片可见并可记录地址 |
| T02 | 正确/错误密码、不存在用户 | 行为正确，数据库只存密码哈希 |
| T03 | 退出后访问接口，普通用户导入 | 分别 401/403，无业务变化 |
| T04 | 用户 A 访问或重试 B 的练习 | 404，不泄漏题目、答案或学习记录 |
| T05 | 正确、错误、空答案、合法拼写变体 | 固定题目版本和策略判分，可回查 |
| T06 | 双击或并发同答案 | 一个实例一条 attempts，统计仅增加一次 |
| T07 | 已作答实例换答案提交 | 409，旧答案不覆盖，重练新建实例 |
| T08 | 写答案后、更新统计前注入异常 | 整笔回滚，不出现事实/统计不一致 |
| T09 | 切换或同时选择考试目标 | 历史保留，共有词去重，未测词义仍未测试 |
| T10 | 发布题目新版本后查看旧练习 | 旧题干、答案和规则仍可解释 |
| T11 | 停用内容或撤销目标关联 | 不选停用内容，历史仍可解释 |
| T12 | 重复关系、悬空词义、空答案导入 | 行级错误，正式数据无部分污染 |
| T13 | 暂停模型后继续练习 | 答案保存，模型页明确不可用 |
| T14 | 从真实正误记录重建状态 | 计数、阶段、复习时间与当前投影一致 |

T02—T14 在业务实现后使用独立测试库运行，不能重置真实用户数据。当前骨架的模型缺失启动检查不替代 T13 的完整答题路径。

## 证据与交接

`evidence/exp01`—`exp04` 每个目录用 index.csv 记录文件、对应要求、生成命令、UTC 时间与说明。演示账号日志明确标记为演示，不充当学习效果或独立模型指标。

四份报告保留课程模板结构，按真实结果填写分析与总结；姓名、学号、班级、实际实验时间、成绩和签字由相应责任人填写。最终交付源码、SQL/迁移/种子、ER 图、内容来源、模型清单、评价、报告和可复现启动说明。备份恢复步骤在持久化能力实现时随数据库交接提供。

答辩路径：基础页 → 登录 → 六级目标 → 含错误练习 → 复习计划 → 增加雅思并展示历史复用 → ML 合法输入 → DL 英语查询 → MySQL 推理事件。每一步明确规则结果与模型输出。
